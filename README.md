# TM/HM Move Names
This mod shows the move names next to TM/HM numbers (Gen 2 style) for Gen1Recomp.
Long names are shortened until you hover over them, this can be turned off in the mod options if you would rather them just be truncated.
This works with the player's inventory, the pc, and shops.
Full disclosure this was made with the help of AI.

Now with Gen 2 Support for the Shops / Game Corners! 
(keeping scroll long names on is recommended for the gen 2 game corners)
