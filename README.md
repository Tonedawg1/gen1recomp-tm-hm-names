# TM/HM Move Names

A simple quality-of-life mod for Gen1Recomp.

Shows the move name next to TM/HM numbers (Gen 2 style).  
Long names are shortened with a period so they fit cleanly in the bag list.

**Supported games:** Pokémon Red, Blue, and Yellow

## Install
1. Download the latest `.zip` from the Releases page
2. In Gen1Recomp, open the mod manager (F10) → Import mod .zip
3. Enable the mod and restart the game

Full disclosure this was made with AI.
